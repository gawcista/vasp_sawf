# Development rules

This repository reuses VASP subspace-SCDM WIN/MMN/AMN/EIG, extracts selected-band symmetry information from WAVECAR as needed, and uses WannierBerri for localization constrained by space-group symmetry and time reversal. Focus on the six-band SrVO₃ test system before assessing the eight-band tSnS system. The tSnS 6×6×1 mesh must not be reduced.

## Physical and numerical constraints

- The SCDM initial guess and the target Wannier representation are separate inputs. `Projection` sets only the target D; it must not generate or overwrite the original AMN. Record reversible column and cell transformations of the initial guess. Original matrices must remain exactly unchanged.
- Retain every target band, all Gxyz components including Gz, and both spinor components. Do not infer coefficient count from trailing nonzero entries or replace PAW MMN with pseudowavefunction overlaps.
- Check original band mapping, k coordinates/order/folding, complete neighbor relations and G translations, spinor axes, antiunitary conjugation, TR², and group composition. Do not automatically remove bands or average the Hamiltonian in post-processing.
- SOC alone does not establish TRS, and matching energies or NK does not establish a common gauge. For the same numerically validated workflow, use programmatic provenance and matrix-consistency checks without reintroducing repeated manual gauge approval. Still distinguish an SCF input WAVECAR from the WAVECAR saved at the end of the interface calculation.
- Do not ignore nonconvergence or increase existing matrix tolerances to hide failures. WannierBerri's default matrix tolerance is not a physical acceptance threshold for coefficient closure or DFT path errors.
- On 2026-09-24, after reviewing the full reasoning, the user explicitly accepted the SrVO₃ coefficient closure of 2.59e-6 and requested removal of this blocker, superseding earlier trial or pending-acceptance instructions. See `ACCEPTANCE.md` for the reasoning and `vasp_sawf/accepted_closure.json` for dataset binding. Apply that decision automatically to the bound inputs, without `numerical_trial` or repeated manual approval. Pending status in old reports is historical only. Do not relax other checks or claim physical acceptance for unrelated data.
- The three band plots show DFT, ordinary Wannier, and SAWF on the same DFT path, using the original target bands and a common energy reference. Never fabricate a SAWF plot when a trustworthy SAWF result is unavailable.
- Do not add EBR analysis, valley projection, new SCDM algorithms, G filtering, Coulomb/cRPA/fRG, UNK, WANPROJ, or VASP/Wannier90 patches. Ignore remote UNK files; do not request or use them.
- Keep all repository documentation, code comments, messages, and figure text in English. User-facing conversation follows the user's language. Add only necessary code comments. Distinguish measured facts, source-code findings, inferences, and items without physical acceptance; never invent evidence or results. Do not place acceptance-status annotations in scientific figures.
